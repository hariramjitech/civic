1. SYSTEM OVERVIEW & VISION
====================================================================================================
The AI-Powered Smart Infrastructure Monitoring and Civic Issue Management System ("Civic Platform") 
is an end-to-end web-based platform designed to transform traditional municipal governance and civic issue 
resolution into an automated, transparent, data-driven, and citizen-empowered ecosystem.

In modern municipalities, citizen feedback regarding damaged roads, water leakages, overflow garbage bins, 
drainage blockages, and non-functional streetlights remains bottlenecked by outdated manual processes. 
The Civic Platform solves these challenges by combining modern web technologies (React + Vite + Leaflet), 
multimodal Artificial Intelligence (Google Gemini 2.5/3.0 Flash), 2dsphere spatial deduplication, real-time 
WebSockets, and automated multi-tier administrative escalation engines.

3. MAIN FEATURES LIST
====================================================================================================

1. Multimodal Gemini AI Triage Engine:
   - Auto-extracts issue categories ('roads', 'sanitation', 'water', 'electricity', 'municipal').
   - Predicts severity level ('low', 'medium', 'high', 'critical').
   - Performs visual relevance analysis and detects irrelevant or stock imagery.

2. EXIF Forensic & GPS Metadata Analyzer:
   - Extracts camera model, timestamp, and embedded EXIF GPS coordinates from uploaded photos.
   - Calculates distance between camera EXIF coordinates and user-selected map coordinates to tag authenticity.

3. 2dsphere Spatial Deduplication & Upvote Merging:
   - Scans 500m radius using MongoDB `$near` indexing for active issues in the same category.
   - Auto-merges duplicates, incrementing `supportCount` instead of creating redundant departmental tickets.

4. Dynamic Intensity Score & 4-Tier Automated Escalation Engine:
   - Computes live Intensity Score: Intensity = (Likes x 1) + (Support x 2) + (LocalSupport x 4) + (Witnesses x 3).
   - Tier 0 (<50): Assistant Engineer / Field Officer.
   - Tier 1 (50-99): Executive Engineer.
   - Tier 2 (100-199): Superintending Engineer / Department Head.
   - Tier 3 (200+): Municipal Commissioner & Auto-Spawns Public Strike Room.

5. Proximity-Verified Witnessing System:
   - Checks user's real-time browser location against the complaint location.
   - Users within 500m receive "Verified Local Witness" status, adding heavy weight (+4) to the Intensity Score.

6. Official Tamil Nadu District Contact Auto-Attacher:
   - Automatically reverse-geocodes lat/lng into official district boundaries via Nominatim.
   - Attaches designated contact phone numbers, emails, officer names, and official portals directly to the post card.

7. Real-Time Chat & Public Strike Rooms:
   - Ephemeral real-time messaging powered by Socket.io.
   - Generates random anonymous aliases per room (e.g. "Citizen #7F3A") to protect citizen identity.
   - Auto-deletes inactive chat messages after 3 days via MongoDB TTL indexes.

8. Community Self-Fix & Volunteer Campaign Drive:
   - Allows citizens to organize volunteer cleanups or minor repairs for abandoned issues.
   - Features meeting scheduler, volunteer sign-up counter, and material/tool pledge tracker (brooms, trash bags, paint).

9. Mandatory Before/After Resolution Verification:
   - Requires field officers to upload photographic evidence of fixed infrastructure.
   - Unlocks citizen rating (1-5 Stars) and feedback scorecard.

10. Interactive Leaflet GIS Maps & Heatmaps:
    - Displays city-wide complaint markers, cluster groups, severity-based color coding, and density heatmaps.

4. USER FLOWS (STEP-BY-STEP USER JOURNEYS)
====================================================================================================

----------------------------------------------------------------------------------------------------
USER FLOW A: CITIZEN JOURNEY (REPORTING & COMMUNITY ACTION)
----------------------------------------------------------------------------------------------------
[STEP 1: AUTHENTICATION & LOCATION]
  Citizen opens Web App -> Authenticates via Clerk (Email/OAuth) -> Platform loads user profile & home district.

[STEP 2: ISSUE SUBMISSION]
  Citizen clicks "Report Issue" -> Uploads photo -> App fetches browser GPS coordinates [lng, lat] -> User enters Title & Description -> Clicks Submit.

[STEP 3: AI TRIAGE & FORENSICS]
  Server executes EXIF metadata extraction -> Gemini AI classifies category & severity -> Server checks 500m radius for duplicates.
  - If Duplicate: System merges post into primary issue, increments support count, and notifies citizen.
  - If Unique: System creates new Post, calculates anonToken, attaches district contacts, and publishes to feed.

[STEP 4: SOCIAL ENGAGEMENT & WITNESSING]
  Citizen views issue on map feed -> Clicks "I Am Affected Too" (Support) or "Verify as Witness" (if within 500m).
  Server updates Intensity Score dynamically -> WebSockets broadcast live support updates to all viewers.

[STEP 5: STRIKE ROOM & VOLUNTEER CAMPAIGN]
  If issue reaches Tier 3 (>200 intensity), user joins auto-spawned "Public Strike Room".
  User can click "Organize Volunteer Drive" -> Sets date/time/meeting point -> Pledges 2 Trash Bags -> Other citizens join drive.

[STEP 6: RESOLUTION RATING]
  Field officer marks issue resolved with Before/After photo -> Citizen receives notification -> Citizen rates resolution 5 Stars with positive feedback.

----------------------------------------------------------------------------------------------------
USER FLOW B: FIELD OFFICER JOURNEY (INSPECTION & RESOLUTION)
----------------------------------------------------------------------------------------------------
[STEP 1: DASHBOARD ACCESS]
  Officer logs in -> Dashboard filters assigned issues by District and Department (e.g. Chennai Roads Dept).

[STEP 2: FIELD INSPECTION]
  Officer selects high-priority ticket on Leaflet map -> Views GPS coordinates, AI severity, and attached citizen photos -> Navigates to physical location.

[STEP 3: STATUS UPDATING]
  Officer updates status to "IN_PROGRESS" -> Adds official update note ("Repair crew dispatched with asphalt patch").

[STEP 4: SUBMIT RESOLUTION EVIDENCE]
  Upon work completion, officer takes photo of repaired asset -> Uploads photo as "After Image" -> Clicks "Mark as Resolved".

----------------------------------------------------------------------------------------------------
USER FLOW C: MUNICIPAL ADMINISTRATOR JOURNEY (MONITORING & AUDITING)
----------------------------------------------------------------------------------------------------
[STEP 1: EXECUTIVE ANALYTICS VIEW]
  Administrator accesses analytics dashboard -> Reviews city-wide metrics: Total Complaints, Hotspot Zones, Departmental SLA Compliance Rate.

[STEP 2: ESCALATION MONITORING]
  Admin reviews "Critical Escalations Queue" (Tier 2 & Tier 3 issues requiring Superintending Engineer / Commissioner intervention).

[STEP 3: OFFICER & DEPT RE-ASSIGNMENT]
  If a department is lagging, Admin reassigns complaint tickets or updates contact details in the District Contact Directory.

[STEP 4: GOVT REPORT GENERATION]
  Admin selects date range and district -> Clicks "Generate AI Executive Summary" -> System generates downloadable PDF/Excel audit report.
